# Bespoken Training

Student and staff training pages for Bespoken English, an online English training platform whose motto is "learn exactly what you need."

## Pages

| File | Purpose |
| --- | --- |
| `index.html` | Bespoken Training home page |
| `clarity-focus.html` | Your Clarity Focus: a student's Language Clarity objectives |
| `practice.html` | Practice your sound: sound-by-sound practice |
| `record-studio.html` | Word recording studio for recording practice-word audio |
| `trainer.html` | Trainer workspace |
| `admin.html` | Admin panel |
| `staff-login.html` | Staff sign-in |

## Shared Language Clarity scripts

- `lc-taxonomy.js`: the standard list of sound categories
- `lc-practice-words.js`: one-syllable practice words for each sound and position
- `lc-technique-copy.js`: the "why" and technique text students see for each sound category

## Audio

The `.wav` files in `audio/` are recordings of the practice words. Upload new recordings into that folder; the practice page only looks there.
